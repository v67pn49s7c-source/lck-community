관리자 대회·경기 관리

대회 관리 라운드 1~4 · 로드 투 MSI · 플레이-인 · 플레이오프 등 자유롭게 구성

경기 관리 일정 등록 · 결과 입력 (추후 API 연동 자리)

토너먼트라서 아직 팀이 안 정해졌다면 팀 선택에서 "미정 (자리 이름 직접 입력)"을 고르세요. 나중에 팀이 확정되면 아래 목록에서 실제 팀으로 바꾸면 됩니다.
상태를 LIVE로 바꾸면 라이브 페이지와 홈에 실시간 경기로 표시됩니다. 종료로 바꾸고 스코어를 입력하면 예측이 자동 채점되고 지난 결과에 반영됩니다.
지금은 이 화면에서 직접 입력하는 방식이며, 나중에 Riot API 등 외부 데이터 연동 시 이 자리에 "자동 불러오기" 버튼이 추가됩니다.

순위 전적 관리 스테이지별 승·패·세트 — 순위는 자동 계산(포인트=세트 득실차)

경기가 끝나면 해당 스테이지의 승·패·세트 수치를 올려 주세요. 시즌 누적 순위는 모든 스테이지 합산으로 자동 계산됩니다.

선수 관리 로스터는 추정 시드라 틀릴 수 있어요 — 여기서 수정

경기 상세 입력 세트별 KDA·아이템·룬 (추후 API 자동 수집 자리)

종료된 경기를 선택하고 세트를 고른 뒤, 선수별 수치를 입력하고 저장하세요. 입력된 세트는 해당 경기의 라이브 페이지 "경기 상세"에 표시됩니다. 샘플: 8/2 DNS vs BRO 경기에 3세트 입력돼 있음.

안내

모든 데이터는 Supabase 서버(서울)에 저장되어 모든 방문자에게 공유됩니다. 운영 데이터(대회·경기·전적·선수·상세)는 관리자 로그인 상태에서만 수정할 수 있고, 글·댓글·채팅·예측·평점은 방문자 누구나 참여할 수 있습니다.
데이터 백업·복구·계정 관리는 Supabase 대시보드(supabase.com)에서 할 수 있습니다.
