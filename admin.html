경기 관리 일정 등록 · 결과 입력 (추후 API 연동 자리)

토너먼트라서 아직 팀이 안 정해졌다면 팀 선택에서 "미정 (자리 이름 직접 입력)"을 고르세요. 나중에 팀이 확정되면 아래 목록에서 실제 팀으로 바꾸면 됩니다.
상태를 LIVE로 바꾸면 라이브 페이지와 홈에 실시간 경기로 표시됩니다. 종료로 바꾸고 스코어를 입력하면 예측이 자동 채점되고 지난 결과에 반영됩니다.
지금은 이 화면에서 직접 입력하는 방식이며, 나중에 Riot API 등 외부 데이터 연동 시 이 자리에 "자동 불러오기" 버튼이 추가됩니다.

순위 전적 관리 스테이지별 승·패·세트 — 순위는 자동 계산(포인트=세트 득실차)

경기 관리에서 결과를 "종료+스코어"로 저장하면 여기 전적에 자동 반영됩니다 (경기의 스테이지명과 같은 이름의 스테이지가 있을 때 · 경기당 1회 · 반영된 경기는 "순위 반영됨" 표시).
과거 스테이지(Rounds 1-2 등)나 세부 조정은 여기서 직접 수정하세요. 시즌 누적 순위는 "종합 합산"이 켜진 스테이지만 합산합니다.

선수 관리 로스터는 추정 시드라 틀릴 수 있어요 — 여기서 수정

경기 상세 입력 밴픽 · 오브젝트 · 선수 기록 — 빠진 칸만 골라서 채우기

비어 있는 칸은 노란 테두리로 표시됩니다. 출전하지 않은 선수는 챔피언을 비워 두세요 — 저장할 때 자동으로 빠집니다.

수상 관리 베스트 세레모니 · 펜타킬 · 시즌 수상

데이터 수집 Leaguepedia에서 경기·선수 기록 가져오기

미리보기를 먼저 눌러 몇 경기가 잡히는지, 이름을 못 알아본 팀·선수가 있는지 확인하세요. 선수 이름은 닉네임이 같으면 저절로 연결됩니다. 그래도 못 알아본 이름만 아래에서 이어 준 뒤 가져오기를 누르세요. 같은 경기를 다시 가져와도 덮어쓰기라 중복되지 않습니다.
가져오면 세트별 KDA·CS·골드가 저장되어 선수 페이지의 육각형 지표가 채워지고, 경기 MVP(POM)도 함께 들어옵니다. 이미 만들어진 경기의 대회·그룹·시각은 건드리지 않습니다.
지금 진행 중인 라운드부터 받으세요. 라운드 1-2 는 90경기(2,300행)라 혼자 한 번을 다 씁니다. 아이템·룬·오브젝트가 필요한 건 진행 중인 라운드 3-4 이므로 그 버튼을 먼저 누르는 편이 빠릅니다.
한 라운드는 기록이 2,000행이 넘어 한 번에 다 못 받을 수 있습니다. 결과에 '이어받는 중'이라고 나오면 같은 버튼을 한 번 더 눌러 주세요 — 받은 데까지 저장돼 있어 이어서 받습니다. ('시즌 전체'는 아직 못 받은 대회부터 알아서 받습니다)

경기 일정 자동 갱신 Leaguepedia 일정표를 따라갑니다

위 칸의 대회 페이지로 지금 갱신을 한 번 누르면 그 대회가 자동 갱신 대상으로 등록됩니다. 이후에는 매일 새벽 3시(한국 시간)와 방문자가 들어올 때(최소 30분 간격) 일정·시각·스코어가 저절로 맞춰집니다. 새 경기가 생기면 자동으로 추가되고, 이미 순위에 반영한 경기는 건드리지 않습니다.
새 경기의 그룹(스테이지)은 팀을 보고 자동으로 정해집니다 — '순위 전적'에 등록된 그룹 명단을 그대로 씁니다(kt·dk·t1·hle·gen → 레전드 등). 그룹을 바꾸시면 그다음 갱신부터 새 기준으로 배정됩니다.

팀 공식 채널 최신 콘텐츠 자동 수집

YouTube는 채널 ID만 저장하면 RSS로 즉시 수집됩니다. X는 핸들과 Vercel의 X_BEARER_TOKEN, Instagram은 핸들·승인된 사용자 ID와 팀별 INSTAGRAM_ACCESS_TOKEN_팀ID가 필요합니다. 비밀 토큰은 이 화면이나 DB에 입력하지 말고 Vercel 환경변수에만 저장하세요.

중계 링크 오늘의 경기 페이지에 뜨는 "중계 보기" 버튼

치지직·SOOP처럼 채널 주소가 늘 같은 곳은 여기 한 번만 넣으면 이후 모든 경기에 자동으로 붙습니다. 유튜브처럼 경기마다 주소가 다를 때만 아래 "이 경기만 다르게"에 넣으세요 (비워 두면 위 기본 주소를 씁니다).
끝난 경기에는 중계 버튼이 표시되지 않습니다.

오늘의 서사 경기마다 "왜 봐야 하는지" 한 줄 · 안 넣으면 기록에서 자동으로 만듭니다

제목을 비우고 저장하면 자동 서사로 되돌아갑니다. 자동 서사는 우리가 실제로 가진 기록 (직전 맞대결 결과·실제 순위·연승 기록)만 씁니다 — 라이벌 관계나 별명 같은 건 여기서 직접 넣을 때만 나옵니다. 선수를 고르면 홈 상단에 그 선수 얼굴이 크게 걸립니다.
