## 0. 초기화 **전에** 반드시 할 것

깃허브에 **없는** 파일이 5개 있습니다. 초기화하면 **영구히 사라집니다.**

```
.gitignore
home-preview.html
assets/home-preview.css
assets/home-preview.js
docs/CLAUDE_HANDOFF.md
```

이 파일들은 **코덱스(다른 AI)가 만든 것**이라 제가 함부로 깃허브에 올리지 않았습니다.
초기화 전에 셋 중 하나를 하세요.

1. **코덱스에게 "이 파일들 커밋해 줘"** 라고 시킨다 ← 가장 깔끔
2. USB나 클라우드에 **폴더째 복사**해 둔다
3. 필요 없다고 판단되면 그냥 버린다 (되돌릴 수 없음)

그 외에는 **전부 깃허브에 올라가 있습니다.** 커밋 안 된 변경 없음, push 안 된 커밋 없음.

## 3. 비밀번호·키는 어디에 있나

**전부 서버에 있고 맥북에는 없습니다.** 초기화해도 안 잃어버립니다.

Vercel → 프로젝트 → Settings → Environment Variables 에 있는 이름들:

```
SUPABASE_URL              데이터베이스 주소
NAVER_API_KEY_ID          네이버 뉴스 검색 (Client ID)
NAVER_API_KEY             네이버 뉴스 검색 (Client Secret)
CRON_SECRET               자동 수집용 열쇠
ADMIN_TASK_TOKEN          관리 작업용 열쇠
INSTAGRAM_ACCESS_TOKEN    (현재 미사용)
X_BEARER_TOKEN            (현재 미사용)
```

⚠ **값을 AI 대화창에 붙여넣지 마세요.** 스크린샷도 마찬가지입니다.
   실수로 노출됐다면 그 서비스에서 **재발급** 하고 Vercel 값을 바꾸면 됩니다.

⚠ Supabase 의 `service_role` 키는 **Vercel 에만** 넣습니다. 코드에 절대 넣지 않습니다.

## 4. 작업할 때 지키는 규칙 (AI 에게도 해당)

1. **프레임워크 도입 금지.** 빌드 도구 없이 굴러가는 게 이 사이트의 생존 조건입니다 (AGENTS.md 6.5).
2. **배포 전 `bash tests/check.sh`.** 실패하면 push 하지 않습니다.
3. **자산 버전(`?v=20260817x`)을 올려야** 방문자가 새 파일을 받습니다. check.sh 가 강제합니다.
4. **`git add -A` 금지.** 남(코덱스)의 파일까지 커밋됩니다 — 실제로 한 번 사고가 났습니다.
   내 파일만 이름으로 지정해서 add 합니다.
5. **SQL 은 파일로 만들고 사람이 실행**합니다. `supabase/*.sql` 을 Supabase SQL Editor 에 붙여넣습니다.
6. **없는 사실을 지어내지 않습니다.** 라이벌 관계·별명·기록은 실제 데이터에 있을 때만 씁니다.
7. **화면을 고쳤으면 실제로 열어서 재 봅니다.** 눈으로 보기 전에 "됐습니다"라고 하지 않습니다.

## 6. 다음에 할 일 (우선순위 순)

### ★ 1순위 — 끝난 경기가 조용히 '예정'으로 되돌아가는 문제
`api/schedule-sync.js:171` 에 "이미 done 이면 done 으로 둔다" 는 분기가 없습니다.
점수는 그대로 둔 채 상태만 되돌아가 **"아직 안 한 경기인데 2:0"** 이 됩니다.
그러면 순위표에서 그 경기가 사라지고, 경우의 수 엔진이 그 경기를 **"남은 경기"로 다시 세면서**
확정·무산 판정이 뒤집힙니다. Leaguepedia 가 막히면 **사람이 아무것도 안 해도 발동**합니다.
→ **한 줄 수정.** 되돌리지 말고 경고로 올리는 방식으로.

### 2순위 — 스테이지 이름이 바뀌면 "전원 플레이오프 확정"
관리자 화면에서 스테이지 이름을 바꾸면 경우의 수 엔진이 "남은 경기 0건" 이 되는데,
정합성 검사가 `0 !== 0` 이라 **통과합니다**. 재료를 못 찾으면 계산을 포기하도록 바꿔야 합니다.

### 3순위 — 관측 장치가 없다
방문 통계 0건 · 오류 수집 0건입니다. 어떤 브라우저에서 코드가 터지면
그 사람은 **흰 화면**을 보고 운영자는 영원히 모릅니다.

### 그 밖
- 서버가 미국에 있음 (DB 는 서울) → `vercel.json` 에 `"regions": ["icn1"]` 한 줄
- 운영자 공지 글쓰기 UI (서버는 이미 허용, 화면만 막혀 있음)
- 오프시즌(11월~) 홈 대책 — 경기가 없으면 홈의 주요 블록이 통째로 사라짐
- 월즈 스킨 재제작

더 자세한 진단은 대화 기록의 **"종합 브리핑"** 에 있습니다 (10개 관점 · 제안 63건).
